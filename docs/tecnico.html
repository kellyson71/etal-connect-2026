Abrir sem instalar

Abra index.html no Chrome. CSS, JavaScript, fontes, QR ilustrativos e logotipo utilizados estão incorporados. A prancha abre pelo caminho relativo maps/bloco-principal.svg; mantenha essa pasta junto ao HTML. Links SUAP e referências externas continuam externos.

A exportação usa navegação por fragmentos #tela=... para funcionar em file://. O aplicativo hospedado original usa parâmetros ?tela=.... Esse ajuste é aplicado somente durante a exportação e não altera o código-fonte da experiência hospedada.

Editar e atualizar a exportação

Use Node.js 22.13 ou superior e npm. A primeira instalação requer internet. As dependências não foram incluídas na entrega.

npm ci
# editar app/ ou public/
python3 scripts/build-principal-plan.py  # somente ao mudar a geometria
npm run export:html
python3 scripts/build-export-docs.py     # somente ao mudar esta documentação

Reabra index.html após gerar. Opcionalmente, sirva a pasta com npm run preview:html e abra http://127.0.0.1:8080.

Bibliotecas e arquitetura atuais

React 19 e TypeScript; React Native for Web para View, Text, Pressable, TextInput e StyleSheet; React Hook Form; Motion; Lucide; react-zoom-pan-pinch; CSS/Tailwind. O projeto original usa Vinext/Vite e infraestrutura de Sites/Cloudflare. A exportação HTML usa Vite diretamente, sem servidor e sem hospedar nada.

app/components/etal-app.tsx concentra navegação e estado. Os mapas e campeonatos têm componentes separados. app/components/native.ts importa os módulos React Native Web individualmente. No Site original, app/page.tsx carrega o aplicativo apenas no cliente com ssr:false; manter isso ao trabalhar na versão hospedada.
